# Radiant Magic generation record

Created 2026-10-13 using the built-in OpenAI image-generation tool with `transparent_background: true`. The tool did not expose its resolved model snapshot. All three selected PNGs retain their alpha channels. This pass uses generated textures and Three.js animation, shaders, and lights; Blender was not used for the spell effects.

Sources are preserved in `art/`. `scripts/process-magic-assets.mjs` crops the two 3-by-2 atlases and packages 15 WebP runtime textures in `public/assets/magic/`. Spark and danger-sigil textures are grayscale derivatives of the generated lightning core and wind sigil, retaining their alpha. Runtime core and sigil cells are 512 square pixels; the trail is 1536 by 512.
